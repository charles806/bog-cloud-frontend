Authentication

All API requests must include your API key in the Authorization header.

Authorization: Bearer bog_your_api_key_here

Generate keys on the API Keys page.

Base URL

https://api.bogcloud.com/v1

Endpoints

GET /files

List all files for the authenticated user.

curl -H "Authorization: Bearer YOUR_KEY" https://api.bogcloud.com/v1/files
POST /files/upload

Upload a new file.

curl -X POST -H "Authorization: Bearer YOUR_KEY" -F "file=@file.pdf" https://api.bogcloud.com/v1/files/upload
